# 🪵 Pauly Bruv Engraving — Official Website

The official website for **Pauly Bruv Engraving**, designed to showcase bespoke laser-engraved merchandise—including slate coasters, Brummie slang wood magnets, and 3D-layered MDF street signs—and handle custom order inquiries.

---

## ✨ Features

* 🪵 **Product Showcase:** Responsive catalog presenting slate coasters, wooden slang magnets, and custom display stands.
* 📏 **Interactive MDF Sign Builder:** Real-time sign text customizer with character counting and dual color finish preview.
* 📬 **Integrated Contact Pipeline:** Automatic query-parameter pre-filling from product pages into the contact form.
* ♿ **Accessible & Validated:** Fully compliant with W3C HTML5 / CSS3 validation and optimized for high Google Lighthouse scores.

---

## 🛠️ Tech Stack

* **Markup & Structure:** HTML5 (Semantic & Accessible)
* **Styling:** Bootstrap 5.3.3 & Custom CSS3
* **Scripting:** Vanilla JavaScript (ES6+)
* **Deployment:** GitHub Pages / Vercel
