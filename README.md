# 🪵 Pauly Bruv Engraving — Official Website

The official website for **Pauly Bruv Engraving**, designed to showcase bespoke laser-engraved merchandise—including slate coasters, Brummie slang wood magnets, and 3D-layered MDF street signs—and handle custom order inquiries.

---

## ✨ Features

* 🪵 **Product Portfolio:** Dynamic gallery displaying custom slate, wood, and MDF products.
* 📬 **Order & Inquiry Form:** Simple, direct contact integration for custom job requests.
* 📱 **Mobile-First Design:** Fully responsive layout built to look clean on mobile, tablet, and desktop.
* ⚡ **Fast Performance:** Lightweight code with clean UI elements and fast asset loading.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Modern JavaScript (ES6+)
* **Styling:** Tailwind CSS
* **Icons:** Lucide Icons / FontAwesome
* **Deployment:** Vercel / GitHub Pages
